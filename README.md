# Minecraftgame

A fresh original 3D voxel sandbox prototype built with Godot 4.3.

## Play
- WASD: move
- Mouse: look
- Space: jump
- Left click: break the targeted block
- Right click: place a block
- 1: Survival mode (limited blocks)
- 2: Creative mode (unlimited blocks)
- Esc: release the mouse

This is an original Minecraft-inspired project, not the official Minecraft game.

## Build
The GitHub Actions workflow exports a Windows x86_64 executable and uploads it as the `Minecraftgame-Windows` artifact.
